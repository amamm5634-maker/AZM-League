# دوري عزم — جامعة بحري

موقع عربي (RTL) للدوري العام لكليات جامعة بحري (دفعة 23/24): 16 كلية، 4 مجموعات، المباريات والنتائج والترتيب والفرق واللاعبون والأخبار.
مبني بـ **React + TypeScript + Vite**، ويُنشر كموقع ثابت (Static).

## التصميم

هوية "ليلة المباراة": حبر نيلي وعشب وطباشير وذهبي. الخطوط **Lalezar** (العناوين والأرقام) و**IBM Plex Sans Arabic** (النصوص) تُحمَّل من Google Fonts، فتحتاج نت عند أول فتح وإلا يُستخدم خط النظام. الألوان في أول `src/styles.css` (المتغيرات `--ink` و`--pitch` و`--gold`).

## التشغيل

```bash
npm install
npm run dev        # تشغيل محلي على http://localhost:5173
npm run build      # بناء النسخة النهائية داخل dist/
npm run check      # فحص الأنواع + سلامة البيانات + منطق الجدول والإدارة
```

يتطلب Node.js 18 أو أحدث.

## النشر (Netlify أو Cloudflare Pages)

- أمر البناء: `npm run build` — مجلد الإخراج: `dist`
- أسرع طريقة: `npm run build` ثم اسحب مجلد `dist` على `app.netlify.com/drop`.
- بعد أي تعديل على الملفات: ابنِ من جديد وارفع `dist` مرة أخرى.

## تحديث الموقع (كل شيء من ملفات البيانات)

| المهمة | الملف |
| --- | --- |
| تغيير التواريخ والاسم والنظام والتواصل والميدان | `src/data/config.ts` |
| **يوم القرعة (7/11):** كتابة نتيجة القرعة | `src/data/draw.ts` |
| إضافة لاعبي كل كلية | `src/data/rosters.ts` |
| إضافة خبر | `NEWS` داخل `src/data/seed.ts` |
| ألوان الكليات وأسماؤها | `COLLEGES` داخل `src/data/seed.ts` |

### يوم القرعة
افتح `src/data/draw.ts` واكتب أسماء الكليات في كل مجموعة (4 لكل مجموعة)، ثم `npm run check` للتأكد، ثم ابنِ وارفع.
يتولد تلقائياً: صفحة المجموعات، جداول الترتيب، و24 مباراة بمواعيد `SCHEDULE` في `config.ts` (مواعيد مقترحة، عدّلها).

### إضافة لاعبين وصورهم
1. ضع صورة اللاعب في `public/players/` (مثل `hendasa-9.jpg`، يفضّل صورة عمودية).
2. أضفه في `src/data/rosters.ts`:
   ```ts
   'هندسة': [
     { name: 'اسم اللاعب', number: 9, position: 'مهاجم', photo: 'players/hendasa-9.jpg' },
   ],
   ```
3. بدون `photo` تظهر صورة رمزية. تتكوّن بطاقة اللاعب والتشكيلة 4-3-3 تلقائياً حسب المراكز.

### إضافة خبر بصورة
ضع الصورة في `public/news/` وأضف `image: 'news/photo.jpg'` للخبر في `NEWS`.

## لوحة الإدارة

الرابط `#/admin` (غير مرتبط من الموقع العام).
- **بدون Supabase:** وضع تجريبي برمز `1234`، والنتائج تُحفظ في متصفحك فقط.
- **مع Supabase (الحي):** دخول بالبريد وكلمة المرور، وكل دور يرى قسمو: `admin` (كل شيء)، `scorer` (النتائج والأهداف)، `editor` (الأخبار والصور)، `photographer` (رفع الصور فقط)، والأدمن يرى كل شيء ويدير الطاقم من تبويب «الطاقم». الخطوات الكاملة في **`SUPABASE.md`**.

## حدود النسخة الحالية (مهم)

- بدون Supabase: نتائج اللوحة محلية في متصفح كل شخص ولا تظهر للزوار، والرمز `1234` ليس مصادقة حقيقية.
- مع Supabase: النتائج والأخبار تظهر للجميع، والصلاحيات تُفرض في الخادم (RLS).
- المحتوى (الفرق واللاعبون والقرعة) يأتي دائماً من الملفات في `src/data`.
- معرض الصور يعمل مع Supabase فقط (يحتاج تخزين ملفات). في النسخة التجريبية تظهر صفحة المعرض فارغة.

## الانتقال إلى Supabase لاحقاً

كل الوصول للبيانات يمر عبر `TournamentRepository` في `src/services/repository.ts`.
اكتب `SupabaseRepository` بنفس الدوال وبدّل السطر الوحيد في `src/services/index.ts`.
